# 🍽️ 찍먹 · JJICK-MEOK

### 20대를 위한 맞춤 문화활동 추천 서비스
**"새로운 취향을, 가볍게"**

</div>

<br>

전시·클래스·강연·동아리… 활동은 많아졌지만 **나에게 맞는 활동을 찾기는 여전히 어렵습니다.**
찍먹은 취향 온보딩과 **스와이프 탐색**으로, 흩어진 활동 정보를 모아 **나에게 맞는 활동을 골라주고** 저장부터 신청까지 이어주는 모바일 앱입니다.

> 20대 설문(184명) 결과, 새로운 활동을 찾을 때 가장 큰 불편은 "나에게 맞는지 판단하기 어렵다"(52.7%)였습니다.
> 찍먹은 *더 많이 보여주는* 서비스가 아니라 *골라주는* 서비스를 지향합니다.

<br>

## ✨ 핵심 경험

| | |
|---|---|
| 🗂️ **모으고** | 여러 채널에 흩어진 활동 정보를 한곳에서 탐색 |
| 🎯 **맞추고** | 취향 온보딩 기반 개인 맞춤 추천 · 취향 일치도 제공 |
| ❤️ **이어주고** | 스와이프로 가볍게 탐색하고, 찜부터 신청까지 연결 |
